# Foqus — Speed Reading App

Foqus is an Android speed reading application for EPUB books. It uses a technique called RSVP (Rapid Serial Visual Presentation) combined with ORP (Optimal Recognition Point) highlighting to help users read faster without losing comprehension.

## What is RSVP?
Rapid Serial Visual Presentation displays one word at a time, eliminating the unnecessary eye movement that slows most readers down. The key letter in each word — the Optimal Recognition Point — is highlighted in red, giving your brain a fixed anchor to focus on.

## Features
- Import EPUB books from your device
- RSVP reader with ORP letter highlighting
- Adjustable reading speed from 100 to 1000 WPM
- Word mode and Sentence mode
- Delayed mode for longer words
- Draggable progress bar scrubber
- Book covers extracted from EPUB files
- Custom background image with opacity control
- Color customization (background, highlight, text)
- Cloud sync via Firebase Firestore
- Google Sign In and Email/Password authentication
- Reading progress saved per chapter
- FAQ and settings bottom sheet

## Tech Stack
- **Framework:** Flutter (Dart)
- **Backend:** Firebase (Auth + Firestore)
- **Authentication:** Email/Password, Google Sign In
- **Storage:** Local device storage + Firestore cloud sync
- **Packages:** epubx, image_picker, flutter_colorpicker, google_sign_in, file_picker

## Publishing
Foqus is currently in closed testing on Google Play with active testers. Working toward full production release.
